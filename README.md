# Hi, I'm ENVYLin 👋

Exploring Python automation, OCR, browser automation, and AI-assisted workflows.

## About Me

I'm interested in turning repetitive, manual tasks into small, useful, and maintainable tools. I'm building my technical portfolio through hands-on experiments, practical prototypes, and clear documentation.

My focus is on learning by building: testing ideas, recording limitations, and making examples reproducible before presenting them as finished projects.

## Areas I'm Exploring

- **Python automation** — scripting, data processing, and small productivity tools.
- **OCR and document workflows** — experimenting with RapidOCR to extract text from images and structure it into tables.
- **Browser automation** — exploring Playwright for repeatable browser interactions and testing on suitable demo pages.
- **AI-assisted workflows** — documenting practical ways to combine AI tools with everyday research, writing, and automation tasks.

## Current Focus

These are development directions, not claims of completed or publicly released projects:

- Explore an OCR workflow that converts sample screenshots into structured data for CSV or Excel, with a way to review uncertain results.
- Build generic browser-automation examples using public demo pages and synthetic data.
- Document reusable AI workflows with clear setup instructions, examples, and known limitations.

## How I Approach Projects

- Prefer small examples that are easy to run and understand.
- Use synthetic or appropriately licensed sample data in public repositories.
- Document setup steps, test coverage, known limitations, and future improvements.
- Treat privacy, security, and responsible data handling as part of the design—not as an afterthought.
- Avoid claiming that a prototype is production-ready before it has been tested.

## Open Source Goals

I'm building my public portfolio step by step. As projects become reproducible and documented, I'll publish them here and welcome feedback, issue reports, documentation improvements, and other constructive contributions.
